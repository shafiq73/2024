# 📊 Life Expectancy Data Analysis using ydata-profiling

## 📖 Project Description
This project performs a comprehensive exploratory data analysis (EDA) on a Life Expectancy dataset using the Python library **ydata-profiling**. The goal is to automatically generate insights about life expectancy trends, demographic factors, and health-related indicators in different countries.

By leveraging ydata-profiling, this project provides a detailed data report in a fraction of the time it would take to manually analyze the dataset. It includes summaries of numerical and categorical features, missing values, correlations, and overall data quality.

---

## 🎯 Objectives
- Automate exploratory data analysis on life expectancy data  
- Identify trends, patterns, and anomalies in health and demographic data  
- Detect missing values, duplicates, and feature relationships  
- Generate professional interactive reports in HTML format  
- Provide actionable insights for health data analysis and research

---

## ⚙️ Project Workflow

### 1. Load Dataset
- Dataset imported using Pandas
- Basic preview to understand structure

### 2. Automated Data Profiling
- Used ydata-profiling to generate an EDA report  
- Analyzed all numerical and categorical features automatically

### 3. Report Generation
- Produced an interactive HTML report for easy exploration and sharing

---

## 📊 Key Features of ydata-profiling in this Project
- Overview of dataset: rows, columns, missing values, memory usage  
- Feature type detection: numerical, categorical, date-time  
- Statistical summaries: mean, median, min/max, standard deviation  
- Distribution visualizations for all variables  
- Correlation analysis to identify relationships between health indicators  
- Data quality alerts highlighting potential issues in the dataset
