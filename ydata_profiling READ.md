# 📊 Automated Exploratory Data Analysis using ydata-profiling

## 📖 Project Description
This project demonstrates automated exploratory data analysis (EDA) using the powerful Python library :contentReference[oaicite:0]{index=0}. Instead of manually analyzing datasets, this tool generates a comprehensive and detailed report in just a few lines of code.

The main goal of this project is to simplify and accelerate the data understanding process by automatically generating insights such as data distributions, correlations, missing values, and data quality issues.

---

## 🎯 Objectives
- Automate exploratory data analysis (EDA)
- Quickly understand dataset structure and quality
- Identify missing values, duplicates, and anomalies
- Analyze feature distributions and relationships
- Generate a professional data report in HTML format

---

## ⚙️ Project Workflow

### 1. Data Loading
- Imported dataset using Pandas

### 2. Automated Data Profiling
- Generated profiling report using ydata-profiling

### 3. Report Generation
- Created an interactive report inside Jupyter Notebook
- Exported report to HTML format for sharing

---

## 📊 Key Features of ydata-profiling
- Overview of dataset (rows, columns, memory usage)
- Automatic detection of data types
- Missing values and duplicates analysis
- Statistical summaries (mean, median, distribution)
- Correlation analysis between features
- Data quality alerts and warnings
- Interactive visualizations

ydata-profiling provides a “one-line EDA solution” that generates detailed reports including statistics, correlations, and data quality insights. :contentReference[oaicite:1]{index=1}
