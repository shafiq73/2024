# 📊 SQL + JavaScript Data Analysis Project

## 🔍 Overview
This project demonstrates the integration of **SQL** and **JavaScript** for data analysis and visualization. It showcases how structured data can be queried efficiently using SQL and then visualized interactively using JavaScript.

The goal of this project is to combine backend data processing with frontend visualization to create meaningful insights.

---

## 🧰 Technologies Used
- 🐍 Python (Jupyter Notebook)
- 🗄️ SQL (SQLite)
- 🌐 JavaScript (Chart.js)
- 📊 Data Visualization
- 📁 Pandas (Data Handling)

---

## ⚙️ Key Features
- ✅ Data extraction using SQL queries  
- ✅ Data cleaning and preprocessing  
- ✅ Integration of SQL inside Python environment  
- ✅ Interactive charts using JavaScript (Chart.js)  
- ✅ Histogram and data distribution analysis  
- ✅ Real-time visualization in notebook
