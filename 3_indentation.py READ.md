# Python Indentation 🐍

[![Python](https://img.shields.io/badge/python-3.x-blue)](https://www.python.org/)

## 📌 Project Description
This Python script demonstrates the **importance of indentation in Python**.  
Python uses indentation to define **code blocks** instead of braces `{}` like other languages.  
Proper indentation ensures code runs correctly, especially in:

- Conditional statements (`if`, `elif`, `else`)  
- Loops (`for`, `while`)  
- Function definitions (`def`)  
- Class definitions (`class`)  

The script teaches beginners how to avoid **IndentationError** and write clean, readable Python code.

---

## 🛠 Tools & Libraries Used
- Python 3.x  
- Any IDE, text editor, or Google Colab / Jupyter Notebook  

---

## 📌 Key Concepts Covered
- Proper indentation rules in Python  
- Examples of `if`, `else`, and `elif` blocks  
- Loop indentation (`for` and `while`)  
- Function indentation and scope  
- Common mistakes and errors caused by wrong indentation  

---

## 📈 Conclusions & Insights
- **Indentation is mandatory in Python**; incorrect indentation causes runtime errors.  
- Proper indentation improves **code readability** and maintainability.  
- Beginners must practice consistent indentation (typically 4 spaces) for all Python code.  
- This script is ideal for understanding how Python structures code blocks and avoids syntax errors.
