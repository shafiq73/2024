# 🌍 Life Expectancy Analysis & Prediction

## 📌 Project Overview
This project explores global life expectancy trends using a comprehensive health and demographic dataset from the World Health Organization (WHO). The notebook provides a complete end-to-end workflow, including data cleaning, exploratory data analysis (EDA), visualization, and predictive modeling.  

It transforms raw data into actionable insights, revealing how health, socioeconomic, and lifestyle factors influence life expectancy across countries.

---

## 🎯 Project Objectives
- Clean and prepare global health datasets for analysis  
- Perform statistical analysis and visual exploration of life expectancy drivers  
- Build and evaluate regression models to predict life expectancy  
- Identify key features that impact longevity  
- Provide a reproducible workflow for data science learning and professional use  

---

## 🧠 Dataset Summary
The dataset includes health, socioeconomic, demographic, and lifestyle features for multiple countries over several years. Key variables include:  
- **Life expectancy** (target variable)  
- **Adult mortality**  
- **Infant & under-five deaths**  
- **GDP per capita**  
- **BMI and health risk factors**  
- **Population metrics**  
- **Schooling and economic indicators**  

---

## 🛠️ Tools & Technologies
- **Python**  
- **Pandas & NumPy** → Data cleaning and numerical analysis  
- **Matplotlib & Seaborn** → Data visualization and exploration  
- **Scikit-learn** → Regression modeling and evaluation  
- **Jupyter Notebook** → Interactive workflow and documentation  

---

## 📊 Key Components

### 📍 Data Preprocessing
- Handling missing values and standardizing column formats  
- Removing outliers and inconsistent entries  

### 🔍 Exploratory Data Analysis (EDA)
- Visualizing life expectancy distributions  
- Correlation analysis between life expectancy and health, socioeconomic, and demographic factors  
- Country-wise and yearly trend analysis  

### 🤖 Regression Modeling
- Implemented and compared multiple regression models  
- Evaluated model performance using R², MAE, and RMSE  
- Interpreted feature importance to identify key drivers of longevity
