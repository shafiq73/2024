## ⚙️ Topics Covered

| Category | Description | Examples |
|-----------|--------------|-----------|
| **Arithmetic Operators** | Perform mathematical operations | `+`, `-`, `*`, `/`, `//`, `%`, `**` |
| **Comparison Operators** | Compare two values | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| **Logical Operators** | Combine conditional statements | `and`, `or`, `not` |
| **Assignment Operators** | Assign or modify variable values | `=`, `+=`, `-=`, `*=`, `/=`, etc. |
| **Bitwise Operators** | Perform bit-level operations | `&`, `|`, `^`, `~`, `<<`, `>>` |
| **Identity Operators** | Compare object identity | `is`, `is not` |
| **Membership Operators** | Check membership in sequences | `in`, `not in` |

---

## 🧩 Example Code

```python
a = 10
b = 5

# Arithmetic Operators
print("Addition:", a + b)
print("Subtraction:", a - b)
print("Multiplication:", a * b)
print("Division:", a / b)

# Comparison Operators
print("Is a greater than b?", a > b)
print("Is a equal to b?", a == b)

# Logical Operators
print("Logical AND:", a > 5 and b < 10)
print("Logical OR:", a > 15 or b < 10)
