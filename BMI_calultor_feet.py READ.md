# BMI Calculator (Feet & Pounds) in Python 🐍

[![Python](https://img.shields.io/badge/python-3.x-blue)](https://www.python.org/)

## 📌 Project Description
This Python script calculates **Body Mass Index (BMI)** using user input for **height in feet** and **weight in pounds**.  

BMI is a measure of body fat based on height and weight and is widely used to classify **underweight, normal weight, overweight, and obesity**.  

The script demonstrates **unit conversion, arithmetic calculations, and conditional statements** to classify BMI results.

---

## 🛠 Tools & Libraries Used
- Python 3.x  
- Any IDE or Google Colab / Jupyter Notebook  

---

## 📌 Key Concepts Covered
- Taking user input with `input()`  
- Converting feet to meters and pounds to kilograms for BMI calculation  
- Performing arithmetic operations to calculate BMI  
- Using `if`, `elif`, `else` to classify BMI  
- Displaying results clearly to the user  

---

## 📈 Conclusions & Insights
- **BMI calculation is a practical example** of Python programming for health applications.  
- Unit conversion allows flexibility to use different measurement systems.  
- Conditional statements categorize BMI into standard ranges:  
  - Underweight  
  - Normal weight  
  - Overweight  
  - Obesity  
- Beginners can extend this script by adding **error handling or interactive features**.

---

## 📌 How to Use
1. Open the script in Python IDE or Google Colab.  
2. Run the script and input your height (feet) and weight (pounds).  
3. View your BMI value and category.  
4. Optionally, modify the script to include **more units, graphical output, or logging**.
