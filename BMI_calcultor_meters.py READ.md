# BMI Calculator in Python 🐍

[![Python](https://img.shields.io/badge/python-3.x-blue)](https://www.python.org/)

## 📌 Project Description
This Python script calculates **Body Mass Index (BMI)** using user input for height (in meters) and weight (in kilograms).  
BMI is a measure of body fat based on height and weight and is widely used to classify **underweight, normal weight, overweight, and obesity**.  

The purpose of this project is to teach beginners how to **take input, perform calculations, and display results with conditions**.

---

## 🛠 Tools & Libraries Used
- Python 3.x  
- Any IDE or Google Colab / Jupyter Notebook  

---

## 📌 Key Concepts Covered
- Taking user input using `input()` function  
- Type conversion (`float`) for calculations  
- Performing arithmetic operations to calculate BMI  
- Using conditional statements (`if`, `elif`, `else`) to classify BMI  
- Displaying results in a user-friendly format  

---

## 📈 Conclusions & Insights
- The script helps understand **basic Python programming concepts** like input, arithmetic operations, and conditionals.  
- BMI calculation demonstrates the practical use of Python in **health and fitness applications**.  
- Conditional statements allow categorization of BMI into standard ranges:  
  - Underweight  
  - Normal weight  
  - Overweight  
  - Obesity  
- Beginners can extend this script by adding **unit conversion, error handling, or graphical output**.  

---

## 📌 How to Use
1. Open the script in Python IDE or Google Colab.  
2. Run the script and input your weight (kg) and height (meters) when prompted.  
3. View your BMI value and the category.  
4. Optionally, modify the script to add more features like height in cm or weight in pounds.
