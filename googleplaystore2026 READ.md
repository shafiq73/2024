📱 Google Playstore 2026 Analysis
Welcome to the Google Playstore 2026 Project.
This notebook explores the Google Play Store dataset using Exploratory Data Analysis (EDA) techniques to uncover insights about mobile applications, user behavior, and market trends.

✨ Project Overview
The goal of this project is to:

Analyze app categories, ratings, reviews, and installs.

Discover patterns in user engagement.

Visualize relationships between app features and performance.

Provide actionable insights for developers, analysts, and researchers.

📂 Dataset Information
The dataset includes:

App Details: Name, Category, Genres, Size, Version, Update date.

User Metrics: Ratings, Reviews, Installs.

Market Attributes: Type (Free/Paid), Price, Content Rating.

Additional Data: User reviews for sentiment analysis.

🔎 Methodology
Data Cleaning

Handling missing values and duplicates.

Standardizing formats (e.g., installs, size).

Exploratory Data Analysis (EDA)

Distribution of ratings and reviews.

Popular categories and genres.

Correlation between installs, ratings, and app size.

Visualization

Bar charts, histograms, scatter plots, and heatmaps using Matplotlib and Seaborn.

📊 Key Insights
Free apps dominate the Play Store, while paid apps are rare.

Games and Tools are the most popular categories.

High installs ≠ High ratings — popularity doesn’t always mean quality.

App size has little impact on user ratings.

User reviews reveal sentiment trends that can guide app improvements.
