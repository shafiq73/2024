# Python Data Structures & Indexing 🐍

[![Python](https://img.shields.io/badge/python-3.x-blue)](https://www.python.org/)

## 📌 Project Description
This Python script demonstrates how to work with **core Python data structures** and access their elements using **indexing**.  
It covers:

- **Lists** – mutable sequences  
- **Tuples** – immutable sequences  
- **Dictionaries** – key-value mappings  
- **Sets** – unordered collections of unique elements  

The purpose is to help beginners **understand how to store, access, and manipulate data** efficiently in Python.

---

## 🛠 Tools & Libraries Used
- Python 3.x  
- Any IDE or Google Colab / Jupyter Notebook  

---

## 📌 Key Concepts Covered
- Creating and initializing lists, tuples, dictionaries, and sets  
- Accessing elements using **index** for lists and tuples  
- Accessing values using **keys** for dictionaries  
- Iterating through data structures using loops  
- Nested data structures and multi-level indexing  
- Modifying mutable data structures (lists, dictionaries)  
- Understanding immutable structures (tuples, frozensets)

---

## 📈 Conclusions & Insights
- **Lists and dictionaries** are versatile for storing and manipulating data.  
- **Indexing** allows easy access to elements, essential for data operations.  
- **Immutable structures** like tuples are safer for storing data that shouldn’t change.  
- Nested structures enable representing complex data, and indexing helps retrieve information.  
- This script is ideal for beginners to practice **data structures and element access in Python**.

---

## 📌 How to Use
1. Open the script in Python IDE or Google Colab.  
2. Run each example to see how data structures are created and accessed.  
3. Modify examples or create your own to practice indexing and manipulation.
