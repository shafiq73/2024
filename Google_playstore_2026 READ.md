# 📱 Google Play Store Data Analysis & Visualization

## 🚀 Project Overview

This project presents a comprehensive data analysis of Google Play Store applications, focusing on uncovering insights about app performance, user behavior, and market trends.

Using real-world data, this analysis transforms raw app information into meaningful visual insights that can help developers, businesses, and analysts make data-driven decisions.

---

## 📊 Dataset Description

The dataset contains detailed information about thousands of Android applications available on the Google Play Store, including:

* App Name
* Category
* Rating
* Reviews
* Size
* Installs
* Type (Free/Paid)
* Price
* Content Rating
* Genres
* Last Updated
* Android Version

This dataset provides a complete view of app performance and user engagement across multiple categories. ([Google Sites][1])

---

## 🎯 Project Objectives

* Analyze app ratings and user engagement
* Identify top-performing categories
* Compare free vs paid applications
* Explore relationships between installs, reviews, and ratings
* Visualize trends and patterns in the app market

---

## 🛠️ Tools & Technologies

* **Python**
* **Pandas** – Data Cleaning & Analysis
* **Matplotlib & Seaborn** – Data Visualization
* **Jupyter Notebook** – Development Environment

---

## 🔍 Key Analysis Performed

* Data Cleaning & Preprocessing
* Handling missing values and inconsistencies
* Category-wise app distribution
* Rating analysis across different categories
* Install trends and popularity analysis
* Free vs Paid app comparison
* Correlation analysis using heatmaps

---

## 📈 Key Insights

* Certain app categories dominate the Play Store market
* Free apps significantly outnumber paid apps
* Apps with higher reviews tend to have better visibility and installs
* Ratings are influenced by both user engagement and app category
* Popular apps follow clear patterns in installs and user feedback
